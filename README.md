# 3D3D

**Open source tools from a working 3D print farm.**
Made in New Brunswick, Canada, for people who build, print and tinker.

[3d3d.ca](https://3d3d.ca)

</div>

We design and print parts for customers every day, and we build the software we wish we had. Everything below runs on your own computer, with your own printers and your own files.

## Projects

| Project | What it is |
|---|---|
| [**Stella Scope**](https://github.com/3d3dcanada/stella-scope-community) | A cockpit and flight recorder for Klipper, Prusa and FlashForge printers. A whole farm on one wall, every printer in 3D, every moment recorded and replayable. AGPL-3.0, no printer limit. |
| [**FORMA**](https://github.com/3d3dcanada/forma) | Local CAD you can talk to. A parametric modeller on a real B-Rep kernel, with text-to-CAD, engineering drawings and print checks. [Desktop downloads](https://github.com/3d3dcanada/forma-desktop). |
| [**snitch**](https://github.com/3d3dcanada/snitch) | Your photo is telling on you. Find out what, make it stop, or put your name on it. EXIF, IPTC/XMP and C2PA, in Rust. |
| [**Alt**](https://github.com/3d3dcanada/alt-cli) | A coding agent in your terminal for the model you choose: local, uncensored or hosted. |
| [**ORA Warden**](https://github.com/3d3dcanada/ora-warden) | A fail-closed MCP server for local AI agents. Your agent does the work; you keep the keys. |
| [**Free Tools**](https://github.com/3d3dcanada/free-tools) | 36 browser tools for design, files and 3D printing, and a 40-lesson printing academy. No account, no upload. |
| [**prusaslicer-3d3d**](https://github.com/3d3dcanada/prusaslicer-3d3d) | Our OrcaSlicer profile set for the Prusa CORE One L, derived from real flow limits. |
| [**Token Stack Workbench**](https://github.com/3d3dcanada/token-stack-workbench) | Measure and verify a Claude Code and Codex token-saving setup. |
| [**Sovereign AI**](https://github.com/3d3dcanada/sovereign-ai) | A local AI workstation: Ollama, OpenWebUI, MCP and ComfyUI on a GTX 1070. |

## Working with us

- **Found a bug or have an idea?** Open an issue on the project. Each repository says how we like contributions to arrive.
- **Need a part designed or printed?** [3d3d.ca](https://3d3d.ca).
- **Security problem?** Report it privately: see [SECURITY.md](https://github.com/3d3dcanada/.github/blob/main/SECURITY.md).
